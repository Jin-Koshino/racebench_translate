# racebench
racebenchは、割り込み並行欠陥検出ツールをテストするためのベンチマークスイート[1]です。NASAC 2019原型竞赛（並行競争クラス）で初めて公開されました。
ルートディレクトリ下のサンプルプログラムは、主に割り込みデータアクセス競合の7つの欠陥パターン[2]を理解するために使用されます。

## 2.0
このディレクトリ下のサンプルプログラムは、最終竞赛で使用されるテストセットの一部であり、2019年11月11日にリリースされ、竞赛参加者がツールをさらにデバッグするために提供されます。
約定：
* 各ディレクトリは完全にコンパイル・実行可能なサンプルプログラムであり、ツールはこのプログラムを独立して分析する必要があります。
* 関数命名規則：\*_mainはメインプログラム、\*isr_[isr_num]は割り込みハンドラエントリ。isr_numが大きいほど、割り込み優先度が高い。
* 各サンプルプログラムの最後の行は、そのサンプル内の潜在的な変数アクセス順序違反BUGをコメントで示します。

## 2.1
このディレクトリは11月20日に公開され、最終的な竞赛のすべてのテストセットになります。
